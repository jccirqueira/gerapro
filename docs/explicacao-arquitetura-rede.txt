┌─────────────────────────────────────────────────────────────────────────────────┐
│                                                                                 │
│  1. O QUE É A ARQUITETURA DE REDE INDUSTRIAL?                                   │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘

Imagine que você está montando o sistema elétrico de uma fábrica. Você tem vários
CLPs (controladores), painéis, sensores, motores, inversores e uma sala de
supervisão. Todos esses equipamentos precisam conversar entre si.

A pergunta é: COMO eles se conectam?

- Que tipo de cabo usar?
- Quantos switches são necessários?
- Como garantir que a rede não pare se um cabo romper?
- Como endereçar cada equipamento?

O módulo de **Arquitetura de Rede Industrial** do GeraPro responde tudo isso
automaticamente. Você informa quais CLPs e equipamentos de campo existem, e o
sistema gera:

  - Um diagrama visual da rede (como um desenho técnico)
  - Uma lista completa de materiais (cabos, switches, conectores)
  - Um memorial descritivo técnico (documento em texto)
  - O custo estimado da rede
  - O plano de endereçamento IP
  - A verificação de conformidade com normas técnicas

Tudo isso para que o engenheiro não precise desenhar do zero ou calcular na mão.

┌─────────────────────────────────────────────────────────────────────────────────┐
│                                                                                 │
│  2. AS TRÊS CAMADAS DA REDE (A Hierarquia)                                     │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘

O sistema organiza a rede em TRÊS NÍVEIS, seguindo o padrão internacional ISA-95.
Pense como uma pirâmide:

          ┌──────────────────────────────────────┐
          │                                      │
          │   NÍVEL GESTÃO / IIoT                │
          │   (Servidores, SCADA, Cloud)         │
          │                                      │
          │   Ex: Gateway, Firewall, Roteador    │
          │                                      │
          ├──────────────────────────────────────┤
          │                                      │
          │   NÍVEL CÉLULA / CONTROLE            │
          │   (CLPs, Switches, IHMs)             │
          │                                      │
          │   Ex: CLP S7-1500, Switch SCALANCE   │
          │                                      │
          ├──────────────────────────────────────┤
          │                                      │
          │   NÍVEL DE CAMPO                     │
          │   (Sensores, Atuadores, Motores)     │
          │                                      │
          │   Ex: SIMOCODE, Inversor, REM        │
          │                                      │
          └──────────────────────────────────────┘

NÍVEL DE CAMPO — É a base. Onde estão os sensores, atuadores, motores e
dispositivos que interagem com o processo físico. Eles se conectam ao CLP
através de um barramento de campo (ex: Profibus DP, Modbus RTU, IO-Link).

NÍVEL DE CÉLULA / CONTROLE — É o cérebro. Onde estão os CLPs, painéis de
comando, IHMs (telas de operação) e os switches que interligam tudo. Aqui
roda o protocolo industrial Ethernet (PROFINET, EtherNet/IP, Modbus TCP).

NÍVEL DE GESTÃO / IIoT — É a supervisão. Onde ficam os servidores de
supervisão (SCADA), firewalls, roteadores 4G/5G e acesso remoto. Conecta
a fábrica ao mundo externo e aos sistemas de gestão (ERP, MES).

┌─────────────────────────────────────────────────────────────────────────────────┐
│                                                                                 │
│  4. AS TOPOLOGIAS (Os Formatos de Ligação)                                     │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘

Topologia é o formato como os equipamentos são ligados entre si. O sistema
suporta 5 tipos:

┌─────────────────────┬──────────────────────────────────────────────────────────┐
│ TOPOLOGIA           │ COMO FUNCIONA                                             │
├─────────────────────┼──────────────────────────────────────────────────────────┤
│ ANEL (MRP)          │ Os dispositivos são ligados em círculo. Se um cabo       │
│                     │ romper, a rede se recupera em menos de 200ms.            │
│                     │ Ideal para processos que não podem parar.                │
│                     │ A versão MRPD recupera em ZERO milissegundos             │
│                     │ (duplicando os dados nas duas direções).                 │
│                     │                                                          │
│ ESTRELA             │ Todos os dispositivos ligados a um switch central.       │
│                     │ Se um cabo romper, só aquele dispositivo sai da rede.    │
│                     │ Simples e fácil de diagnosticar.                         │
│                     │                                                          │
│ LINHA (Daisy-Chain) │ Dispositivos ligados em sequência, um após o outro.     │
│                     │ Economiza cabos, mas se um falhar, os próximos param.    │
│                     │                                                          │
│ ÁRVORE              │ Uma combinação de estrela + linha. Switches core         │
│                     │ (centro) ligados a switches access (nas máquinas).       │
│                     │ Ideal para fábricas grandes com várias áreas.            │
│                     │                                                          │
│ MALHA               │ Várias conexões entre os switches. A mais redundante,    │
│                     │ mas também a mais cara (mais cabos e equipamentos).      │
└─────────────────────┴──────────────────────────────────────────────────────────┘


┌─────────────────────────────────────────────────────────────────────────────────┐
│                                                                                 │
│  5. RECURSOS AVANÇADOS DO PROFINET                                              │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘

Quando você seleciona PROFINET como protocolo, o sistema libera opções
avançadas que permitem refinar a arquitetura. Aqui está o que cada uma faz:

CLASSE DE CONFORMIDADE (CC-A, CC-B, CC-C, CC-D)

  Define o nível de capacidade dos equipamentos:

  CC-A (Básico)       — Para automação predial e infraestrutura simples.
                        Switch não-gerenciável é suficiente. Sem diagnósticos.
                        Velocidade: 100 Mbps.

  CC-B (Diagnóstico)  — Para fábricas que precisam monitorar a saúde da rede.
                        Switch gerenciável com SNMP e informações de topologia.
                        Velocidade: 100 Mbps.

  CC-C (IRT/Motion)   — Para máquinas com sincronismo de eixos, robótica e
                        controle de movimento de alta precisão. Exige switches
                        com chip especial (ASIC ERTEC). Jitter abaixo de 1μs.
                        Velocidade: 100 Mbps a 1 Gbps.

  CC-D (TSN)          — A classe mais moderna (2025+). Permite rodar dados de
                        tempo real e tráfego de TI no mesmo cabo Gigabit sem
                        interferência. Usa TSN (Time Sensitive Networking).
                        Velocidade: 1 Gbps.

TEMPO REAL (RT / IRT)

  RT (Real-Time)      — Tempo real padrão. Ciclo mínimo de 250μs (microssegundos).
                        Jitter de 1 a 10ms. Adequado para 99% das aplicações.

  IRT (Isócrono)      — Tempo real isócrono. Ciclo mínimo de 31,25μs.
                        Jitter abaixo de 1μs (milhões de vezes mais rápido
                        que um piscar de olhos). Para motion control.

REDUNDÂNCIA (MRP / MRPD)

  MRP                 — Media Redundancy Protocol. Se um cabo do anel romper,
                        a rede se recupera em até 200ms. Padrão na indústria.

  MRPD                — Media Redundancy Protocol com zero-loss. Os dados são
                        enviados DUAS VEZES (uma em cada direção do anel).
                        Se um cabo romper, a perda é ZERO milissegundos.
                        Para aplicações críticas (segurança, motion).

PROFIsafe (Segurança)

  Permite enviar dados de SEGURANÇA (como parada de emergência, SIL 3)
  no MESMO cabo que os dados normais. Elimina a necessidade de um segundo
  barramento de segurança. Exige CLPs especiais (F-CPU) e dispositivos
  compatíveis (SIMOCODE failsafe, SIRIUS 3RW55 F).

DISPOSITIVOS SIEMENS

  Quando ativado, o sistema insere equipamentos Siemens reais no lugar
  de dispositivos genéricos:

  - SIMOCODE pro V PN:     Gerenciamento inteligente de motores
                           (proteção contra sobrecarga, falta de fase,
                            medição de corrente e potência)
  - SIRIUS 3RW55:          Soft starter (partida suave de motores)
                           com bypass integrado e PROFINET
  - SINAMICS G120:         Inversor de frequência modular
                           com comunicação PROFIdrive
  - SINAMICS S120:         Servoconversor para motion control multicixos
  - ET 200SP:              Periferia remota de E/S descentralizada

│                                                                                 │
│  6. OS TIPOS DE CABO E CONECTORES INDUSTRIAIS                                   │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘

Diferente de uma rede de escritório (que usa cabos CAT5e comuns), a rede
industrial usa cabos especiais, mais robustos. O sistema oferece 4 tipos:

CABOS:

┌─────────────┬──────────────────────────────────────────────────────────────────┐
│ TIPO        │ ONDE USAR                                                        │
├─────────────┼──────────────────────────────────────────────────────────────────┤
│ Tipo A      │ Instalação fixa — dentro de calhas, eletrodutos e painéis.       │
│ (Fixo)      │ O cabo não se move depois de instalado. O mais barato.           │
│             │                                                                  │
│ Tipo B      │ Instalação flexível — onde há vibração ou movimento ocasional.   │
│ (Flexível)  │ Ex: motores que vibram, painéis que abrem e fecham.             │
│             │                                                                  │
│ Tipo C      │ Altamente flexível — para esteiras porta-cabos (drag chain)      │
│ (Contínuo)  │ que se movem continuamente. Ex: máquinas de embalagem.          │
│             │                                                                  │
│ Tipo R      │ Robótica — para braços robóticos que torcem o cabo              │
│ (Robô)      │ constantemente. Blindagem especial para suportar torção.        │
│             │ O mais caro, mas o único que dura em robôs.                     │
└─────────────┴──────────────────────────────────────────────────────────────────┘

CONECTORES:

┌──────────────────────┬─────────────────────────────────────────────────────────┐
│ CONECTOR             │ ONDE USAR                                               │
├──────────────────────┼─────────────────────────────────────────────────────────┤
│ RJ45 Industrial      │ O conector padrão, igual ao do computador, mas mais     │
│ IP20                 │ robusto (carcaça metálica). Para uso dentro de painéis. │
│                      │ Proteção IP20 (não toma chuva).                         │
│                      │                                                         │
│ M12 D-Coded          │ Conector redondo rosqueável, 4 pinos. Para uso em       │
│ IP65/67              │ campo (na máquina). Resiste a jatos d'água, poeira e    │
│                      │ óleo. Velocidade máxima: 100 Mbps.                      │
│                      │                                                         │
│ M12 X-Coded          │ Conector redondo rosqueável, 8 pinos. Mais rápido,      │
│ IP65/67              │ suporta Gigabit Ethernet. Para câmeras e dados pesados. │
│                      │                                                         │
│ SCRJ                 │ Conector de fibra óptica (POF). Para longas distâncias  │
│ (Fibra)              │ ou ambientes com muito ruído elétrico (solda,           │
│                      │ inversores de potência). Imune a interferências.        │
└──────────────────────┴─────────────────────────────────────────────────────────┘

│  8. PASSO A PASSO NA TELA                                                       │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘

Vamos simular o uso completo:

ETAPA 1 — ACESSAR O MÓDULO
  • No menu lateral, clique em "Arquitetura de Rede" (ícone de rede).
  • Se não houver CLPs na Proposta Técnica ativa, o sistema avisa.

ETAPA 2 — VERIFICAR OS CONTROLADORES
  • O card "Controladores Detectados" mostra os CLPs e REMs encontrados
    na proposta ativa, com seus totais de I/O.

ETAPA 3 — CONFIGURAR OS PARÂMETROS BÁSICOS
  • Protocolo Industrial: escolha PROFINET, EtherNet/IP ou Modbus TCP.
  • Protocolo de Campo: escolha Profibus DP, Modbus RTU ou IO-Link.
  • Topologia: escolha anel, estrela, linha ou árvore.
  • Distância Estimada: quantos metros de cabo aproximadamente.
  • Categoria do Cabo: CAT5e, CAT6, CAT6a ou CAT7.

ETAPA 4 — CONFIGURAR ENDEREÇAMENTO IP
  • IP Base: o início da faixa de IPs (ex: 10.0.0.0).
  • Prefixo: /24 (254 hosts), /23 (510) ou /22 (1022).
  • Quantidade de VLANs: quantas redes virtuais (mín. 1, máx. 10).

ETAPA 5 — ATIVAR RECURSOS EXTRAS
  • SCADA: ativa integração com supervisório via OPC UA.
  • IIoT: ativa integração com Internet das Coisas via MQTT.
  • Fibra Óptica: se a distância for grande ou houver muito ruído.
  • Firewall: adiciona um firewall industrial entre a fábrica e a
    rede corporativa (DMZ).
  • Roteador WAN: adiciona roteador 4G/5G para acesso remoto.
  • Access Point: adiciona Wi-Fi industrial (IWLAN).

ETAPA 6 — CONFIGURAR AVANÇADOS PROFINET (se aplicável)
  • Classe de Conformidade: CC-A, CC-B, CC-C ou CC-D.
  • Tempo Real: RT ou IRT (se for motion control).
  • Redundância: MRP ou MRPD (se for processo crítico).
  • Tipo de Cabo Industrial: A (fixo), B (flexível), C (contínuo) ou
    R (robótica).
  • Conector de Campo: RJ45, M12 D-Coded, M12 X-Coded ou SCRJ (fibra).
  • Dispositivos Siemens: ativa para incluir SIMOCODE, SIRIUS, SINAMICS.
  • PROFIsafe: ativa segurança funcional no mesmo cabo.

ETAPA 7 — GERAR ARQUITETURA
  • Clique em "Gerar Arquitetura" no cabeçalho azul.
  • O sistema processa e exibe o resultado completo.

ETAPA 8 — ANALISAR O RESULTADO
  • Confira o diagrama de topologia (desenho SVG).
  • Veja a lista de materiais e o custo estimado.
  • Veja o plano de IP (VLANs + dispositivos + Station Names).
  • Veja as fichas técnicas e a conformidade normativa.
  • Leia o memorial descritivo.

ETAPA 9 — EXPORTAR
  • JSON: resultado completo em formato de dados.
  • CSV: lista de materiais para planilha.
  • PDF: memorial descritivo para documento.
  • SVG: diagrama da topologia (figura).
  • DXF: diagrama para AutoCAD.

│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘

✅  Coloque as listas de I/O dos CLPs na Proposta Técnica antes de usar
    este módulo. Sem I/O, o sistema não consegue dimensionar os dispositivos
    de campo.

✅  A topologia em ANEL é a mais recomendada para processos contínuos.
    Se um cabo romper, a rede se recupera sozinha em milissegundos.

✅  Use MRPD (em vez de MRP) apenas se você tiver aplicações de motion
    control que não toleram NENHUMA perda de comunicação. MRPD é mais caro
    (precisa de switches especiais).

✅  A classe CC-D (TSN) é a mais moderna, mas exige switches TSN específicos
    e cabos CAT6a ou superiores. Verifique disponibilidade com o fornecedor.

✅  Se a fábrica tiver robôs, use cabo TIPO R para as conexões nos robôs.
    Cabo comum não dura em aplicações com torção constante.

✅  Use conectores M12 para dispositivos em campo (sujeito a respingos,
    poeira, vibração). Use RJ45 apenas dentro de painéis fechados.

✅  Ative "Dispositivos Siemens" se você for usar equipamentos reais da
    Siemens. O memorial e o diagrama ficam mais detalhados e realistas.

✅  O Firewall é OBRIGATÓRIO se a rede industrial tiver acesso à internet
    ou à rede corporativa (proteção contra ataques cibernéticos).

✅  Os Station Names gerados para PROFINET seguem o formato padronizado
    (tag-tipo). Você pode usá-los diretamente na configuração do TIA Portal.

✅  Exporte o memorial em PDF e inclua na proposta técnica. Ele já vem
    formatado com todas as informações técnicas.

⚠️  A topologia LINHA é a mais vulnerável: se um dispositivo no meio da
    linha falhar, todos os seguintes perdem comunicação. Use com cuidado.

⚠️  O custo estimado é aproximado (preços de referência). Sempre solicite
    cotação com fornecedores para valores exatos.

⚠️  Se você mudar a Proposta Técnica (adicionar/remover CLPs), precisa
    gerar a arquitetura novamente para refletir as alterações.

│                                                                                 │
│  11. PROBLEMAS COMUNS E SOLUÇÕES                                                 │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────────┐
│  PROBLEMA: "O sistema diz que não há controladores"                             │
│  SOLUÇÃO:  Você precisa ter equipamentos do tipo "PLC" ou "REM" cadastrados     │
│            na Proposta Técnica ativa, com lista de I/O preenchida.              │
│            Vá em Proposta Técnica, adicione os equipamentos, preencha I/O,     │
│            e volte ao módulo.                                                   │
│                                                                                 │
│  PROBLEMA: "Aparece erro de validação"                                          │
│  SOLUÇÃO:  Verifique se todos os CLPs têm nome (tag) e lista de I/O.           │
│            Se usou caracteres especiais no tag, pode causar erro.              │
│                                                                                 │
│  PROBLEMA: "As opções avançadas do PROFINET não aparecem"                       │
│  SOLUÇÃO:  Selecione "PROFINET" no campo "Protocolo Industrial Ethernet".       │
│            As opções só aparecem quando PROFINET está selecionado.              │
│                                                                                 │
│  PROBLEMA: "O diagrama SVG não aparece"                                         │
│  SOLUÇÃO:  Pode ser erro ao gerar. Verifique se há muitos dispositivos.        │
│            Atualize a página e tente novamente com menos controladores.        │
│                                                                                 │
│  PROBLEMA: "O custo estimado está muito alto / baixo"                          │
│  SOLUÇÃO:  O custo é estimado com preços de referência. Ajuste os parâmetros   │
│            (tipo de cabo, classe de conformidade, etc.) para refletir melhor   │
│            a realidade. Sempre solicite cotação com fornecedores.              │
│                                                                                 │
│  PROBLEMA: "O Station Name não aparece no plano IP"                            │
│  SOLUÇÃO:  Station Name só é gerado quando o protocolo é PROFINET.            │
│            Se estiver usando EtherNet/IP ou Modbus TCP, o campo fica vazio.   │
│                                                                                 │
│  PROBLEMA: "O memorial parece incompleto"                                      │
│  SOLUÇÃO:  Algumas seções do memorial (CC, GSDML, cabos, dados de mercado)     │
│            só aparecem quando PROFINET está selecionado com opções avançadas.  │
│            Elas não aparecem para outros protocolos.                           │
│                                                                                 │
│  PROBLEMA: "Quero gerar uma arquitetura nova mas não consigo"                  │
│  SOLUÇÃO:  Clique no botão "Regenerar" no cabeçalho do resultado.              │
│            Se quiser começar do zero, recarregue a página.                     │
│                                                                                 │
│  PROBLEMA: "Exportei CSV mas não abre direito no Excel"                        │
│  SOLUÇÃO:  O CSV usa separador ";" (ponto e vírgula). Ao abrir no Excel,       │
│            escolha "Importar" e selecione separador ponto e vírgula.           │
│                                                                                 │
│  PROBLEMA: "Exportei DXF mas não aparece nada no AutoCAD"                      │
│  SOLUÇÃO:  O DXF é gerado no formato R12 (compatível com todos os programas).  │
│            Use o comando ZOOM → EXTENTS no AutoCAD para centralizar a vista.   │
