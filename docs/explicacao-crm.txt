┌─────────────────────────────────────────────────────────────────────────────────┐
│                                                                                 │
│  1. O QUE É O CRM?                                                              │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘

Imagine que você trabalha com vendas. Você conhece uma pessoa numa feira, troca
cartão, manda um e-mail, depois outro, agenda uma visita, e um dia ela vira cliente.

Agora imagine que você tem 50 contatos assim ao mesmo tempo. Como lembrar de cada
um? Qual o próximo passo? Quem est├í atrasado? Quem est├í quente?

O CRM (Customer Relationship Management) do GeraPro resolve isso. Ele organiza
todos os seus contatos comerciais (chamados de LEADS) em um funil de vendas,
do primeiro contato até virar proposta.

┌─────────────────────────────────────────────────────────────────────────────────┐
│                                                                                 │
│  Onde o CRM se encaixa no fluxo de trabalho?                                   │
│                                                                                 │
│  1. Você cadastra um LEAD (cliente em potencial) no CRM                        │
│  2. Você acompanha o lead pelo funil: novo → tentando contato → contato        │
│     realizado → qualificado → agendado → visita realizada                       │
│  3. Quando o lead est├í pronto, você clica em "Solicitar Proposta"             │
│  4. O lead vira uma PROPOSTA na Gest├úo de Propostas (status "virou_proposta") │
│  5. A Gest├úo de Propostas assume daqui pra frente                              │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘


┌─────────────────────────────────────────────────────────────────────────────────┐
│                                                                                 │
│  2. OS STATUS DO FUNIL (de onde vem e para onde vai)                           │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘

Cada lead passa por estes est├ígios. Você move ele arrastando no Kanban ou
selecionando o status na lista.

┌─────────────────────┬──────────────────────────────────────────────────────────┐
│ STATUS              │ O QUE SIGNIFICA                                          │
├─────────────────────┼──────────────────────────────────────────────────────────┤
│ Novo                │ Acabou de entrar. Primeiro contato foi feito, mas sem    │
│                     │ resposta ainda.                                          │
│                     │                                                          │
│ Tentando Contato    │ Você j├í tentou ligar/e-mail mas ainda n├úo conseguiu     │
│                     │ falar com a pessoa certa.                                │
│                     │                                                          │
│ Contato Realizado   │ Conseguiu falar! A pessoa demonstrou interesse.          │
│                     │                                                          │
│ Qualificado         │ Passou por uma triagem: tem necessidade, orçamento e     │
│                     │ urgência. ├ë um lead "de verdade".                        │
│                     │                                                          │
│ Agendado            │ Vocês marcaram uma reunião ou visita técnica.            │
│                     │                                                          │
│ Visita Realizada    │ A visita aconteceu. O cliente viu o que você oferece.    │
│                     │                                                          │
│ Virou Proposta      │ ❗ O lead foi convertido em proposta.                     │
│                     │ A Gest├úo de Propostas assume daqui.                     │
│                     │                                                          │
│ Desqualificado      │ O lead n├úo é vi├ível (n├úo tem orçamento, n├úo tem       │
│                     │ necessidade, etc.). Motivo é registrado.                 │
└─────────────────────┴──────────────────────────────────────────────────────────┘

📌 Para "Virou Proposta" e "Desqualificado", é obrigatório preencher o motivo.

📌 Os estágios do funil são totalmente personalizáveis em Configurações > Funil CRM.
   Você pode adicionar, renomear, reordenar, mudar cores e definir regras de negócio
   (como quais estágios permitem solicitar proposta ou são terminais).


┌─────────────────────────────────────────────────────────────────────────────────┐
│                                                                                 │
│  3. VISÃO KANBAN (O Quadro de Tarefas)                                         │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘

A aba "Kanban" mostra um quadro com colunas para cada status. Cada lead é um
cart├úo que você arrasta de uma coluna para outra.

┌─────────────┐  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐
│   NOVO      │  │TENTANDO CONT│  │CONTATO REAL │  │QUALIFICADO  │
│             │  │             │  │             │  │             │
│ [Lead A]    │→│ [Lead A]    │→│ [Lead A]    │→│ [Lead A]    │
│ [Lead B]    │  │             │  │             │  │             │
└─────────────┘  └─────────────┘  └─────────────┘  └─────────────┘

Como usar:
  • Arraste um cartão para mudar o status (os filtros de vendedor, tag, busca
    e data também valem no Kanban, mas todas as colunas sempre aparecem)
  • Clique no cartão para abrir o lead (visão 360°)
  • No topo de cada coluna ficam a soma dos valores estimados, a contagem de
    leads e o botão "+", que cria um lead já naquele estágio
  • Filtre por status, vendedor, tag ou texto na barra superior
  • O score aparece no cabeçalho do cartão, ao lado do nome

📌 O quadro mostra TODOS os estágios do funil — inclusive "Virou Proposta" e
   "Desqualificado". Leads em estágio terminal não podem ser arrastados para
   fora da coluna; se precisar mudar, use a visão 360° (aba Dados).

É a forma mais visual de gerenciar seu funil de vendas.


┌─────────────────────────────────────────────────────────────────────────────────┐
│                                                                                 │
│  4. VISÃO LISTA (A Tabela)                                                     │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘

A aba "Lista" mostra todos os leads em uma tabela, igual a uma planilha. Cada
linha é um lead, cada coluna é uma informação.

Colunas disponíveis (nesta ordem):
  • Seleção (checkbox), Lead (nome, empresa e as tags), Status, Score, Vendedor
  • Valor Est., Prob. (probabilidade do estágio e o valor previsto), Criação,
    Ações (botão para abrir a visão 360°)

Você pode:
  • Ordenar clicando no cabeçalho das colunas (clique de novo para inverter)
  • Filtrar por status, vendedor, tag, texto (busca geral) e por data (campo +
    data inicial + data final) — os filtros ficam na barra acima da tabela
  • Selecionar leads com o checkbox e usar as AÇÕES EM MASSA: mudar status,
    mudar vendedor, adicionar tag, exportar só a seleção, excluir e limpar
  • Importar leads de CSV/XLSX (botão "Importar") — "Modelo" baixa um CSV de
    exemplo no padrão correto
  • Exportar para CSV ou XLSX com os botões acima da tabela
  • Navegar por páginas de 50 leads (botões "Anterior" e "Próxima")
  • Clicar em um lead para abrir a visão 360°

│  6. SCORE DO LEAD (Pontuaç├úo Autom├ítica + Manual)                            │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘

Cada lead recebe uma nota de 0 a 100 chamada SCORE. Ela indica o quanto aquele
lead est├í "quente" (próximo de fechar).

O score é calculado automaticamente assim:

┌────────────────────────────────────────────────────────────────────────────────┐
│ FATOR               │ PESO                                                     │
├────────────────────────────────────────────────────────────────────────────────┤
│ Posição no funil    │ Até 35 pontos: posição do estágio no funil x 5,          │
│                     │ limitado a 35 pontos.                                    │
│                     │                                                          │
│ Valor estimado      │ Até 25 pontos: > R$ 50 mil = +25, > R$ 10 mil = +15,     │
│                     │ > R$ 5 mil = +10 e até R$ 5 mil = +5.                    │
│                     │                                                          │
│ Interações          │ Até 15 pontos: +3 por interação registrada na Timeline,  │
│                     │ contados no máximo 15 interações.                        │
│                     │                                                          │
│ Prazo de interesse  │ Até 10 pontos: vence em até 15 dias = +10;               │
│                     │ até 30 dias = +5.                                        │
│                     │                                                          │
│ Dados do lead       │ Segmento, e-mail, telefone/celular, CNPJ e orçamento     │
│                     │ informado: +5 cada. Cargo: +3.                           │
│                     │                                                          │
│ Ajuste manual       │ O score manual sobrescreve o automático;                 │
│                     │ "Recalcular Automático" volta ao cálculo.                │
└────────────────────────────────────────────────────────────────────────────────┘

📌 O mesmo detalhamento aparece na aba "Score" da visão 360°, com os botões
   "Recalcular Automático" e "Salvar Manual".

📌 No Kanban, o score aparece no cabeçalho do cartão, ao lado do nome.
   Verde = quente (≥ 80), amarelo = morno (≥ 50), vermelho = frio (< 50).


┌─────────────────────────────────────────────────────────────────────────────────┐
│                                                                                 │
│  7. HANDOFF: ENVIAR UM LEAD PARA A GESTÃO DE PROPOSTAS                          │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘

Quando o VENDEDOR avalia que o lead est├í pronto para receber uma proposta,
ele usa a funç├úo "Solicitar Proposta" na aba Aç├Áes da vis├úo 360░.

O que acontece internamente:

1. O status do lead muda para "virou_proposta"
2. Um item é criado automaticamente na Gest├úo de Propostas
3. O ENGENHEIRO (ou respons├ível por propostas) v├í encontrar esse lead
   lá na Gestão de Propostas, com status "proposta_enviada"
4. O vendedor N├O mexe na Gest├úo de Propostas (ele só opera no CRM)
5. O engenheiro N├O mexe no CRM (ele só opera na Gest├úo de Propostas)

├ë uma divis├úo clara:
  🧑‍💼 VENDEDOR   → CRM (até "virou_proposta")
  👷 ENGENHEIRO → Gestão de Propostas (a partir de "proposta_enviada")

📌 O CRM nunca mexe nos status "proposta_enviada", "ganho" ou "perdido" —
   esses s├úo de responsabilidade exclusiva da Gest├úo de Propostas.

o botão "?" de ajuda.

  │     Jo├úo (hoje) │  │     orçamento    │
  │ [ ] Agendar      │  │ [✔] Reuni├úo     │
  │     visita       │  │     com Carlos   │
  └─────────────────┘  └──────────────────┘

Cada cart├úo mostra:
  • Título
  • Lead relacionado (com link para abrir)
  • Data de vencimento (em vermelho se atrasada)
  • Prioridade
  • Tipo (ligaç├úo, reuni├úo, follow-up, etc.)
  • Bot├úo "Concluir" e "Excluir"

📌 As tarefas também aparecem na aba "Tarefas" dentro da vis├úo 360░ de cada lead.
