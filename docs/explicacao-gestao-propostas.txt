┌─────────────────────────────────────────────────────────────────────────────────┐
│                                                                                 │
│  1. O QUE É O Gestão de Propostas?                                               │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘

Imagine que você é um vendedor. Você tem vários clientes em diferentes momentos
do processo de venda:

  • Alguns você acabou de conhecer (primeiro contato)
  • Outros já receberam a proposta e estão analisando
  • Alguns já disseram "sim" (fechado)
  • Infelizmente, alguns disseram "não" (perdido)

O Gestão de Propostas é um QUADRO VISUAL (tipo Kanban) que mostra todos os seus
negócios organizados por etapa. Cada negócio vira um CARTÃO que você move de
uma coluna para outra conforme ele avança.

É como ter um quadro magnético na parede com post-its coloridos — mas dentro do
computador e muito mais inteligente.

┌─────────────────────────────────────────────────────────────────────────────────┐
│                                                                                 │
│  Onde o Pipeline se encaixa no fluxo de trabalho?                             │
│                                                                                 │
│  1. Você cria um Orçamento OU uma Proposta Técnica (PTC)                      │
│  2. Automaticamente, um cartão aparece no Pipeline em "Aguardando Início"      │
│  3. Você move o cartão para "Em Elaboração" quando começa a preparar a        │
│     proposta                                                                   │
│  4. Quando envia a proposta ao cliente, move para "Proposta Enviada"          │
│  5. Se o cliente pede ajustes, vai para "Negociação"                          │
│  6. ❗ Fechou? Vai para "Fechado". Perdeu? Vai para "Perdido"                │
│  7. Durante todo o caminho, você registra interações (ligações, e-mails)      │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘


┌─────────────────────────────────────────────────────────────────────────────────┐
│                                                                                 │
│  2. AS 6 COLUNAS (ETAPAS DA VENDA)                                             │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘

O Pipeline tem 6 colunas fixas. Você NÃO pode criar ou remover colunas — elas
representam o ciclo de vida padrão de uma venda.

┌──────────────────────┬──────┬──────────────────────────────────────────────────┐
│ COLUNA               │ COR  │ O QUE SIGNIFICA                                  │
├──────────────────────┼──────┼──────────────────────────────────────────────────┤
│ Aguardando Início    │ Roxa │ O cartão acabou de ser criado. Ainda não          │
│ (prospect)           │      │ começamos a trabalhar na proposta.                │
│                      │      │                                                    │
│ Em Elaboração        │ ❕   │ A Proposta Técnica está sendo preparada.          │
│ (elaboracao)         │ Laranja │ O engenheiro está dimensionando equipamentos. │
│                      │      │                                                    │
│ Proposta Enviada     │ Azul │ A proposta foi enviada para o cliente.           │
│ (enviado)            │      │ Estamos aguardando o retorno.                    │
│                      │      │                                                    │
│ Negociação           │ ❕   │ O cliente pediu ajustes, descontos ou condições   │
│ (negociacao)         │  Amarela │ especiais. Estamos negociando.               │
│                      │      │                                                    │
│ Fechado              │ ✅   │ O cliente ACEITOU a proposta. Venda concluída!    │
│ (fechado)            │ Verde │ Um PROJETO nasce no módulo Cronograma / DRE.    │
│                      │      │                                                    │
│ Perdido              │ ❌   │ O cliente RECUSOU ou escolheu outro fornecedor.   │
│ (perdido)            │ Vermelho │ A oportunidade foi perdida.                   │
└──────────────────────┴──────┴──────────────────────────────────────────────────┘

📌 REGRA IMPORTANTE: Você só pode AVANÇAR o cartão (nunca voltar). Se um cartão
   está em "Proposta Enviada", você não pode arrastá-lo de volta para "Em
   Elaboração". Isso evita que o histórico seja bagunçado.

   Exceção: quando você "Sobe uma Revisão", o cartão volta para "Aguardando
   Início" (explicado na seção 9).


┌─────────────────────────────────────────────────────────────────────────────────┐
│                                                                                 │
│  3. COMO OS CARTÕES APARECEM NO PIPELINE?                                      │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘

Os cartões NÃO são criados manualmente. Eles aparecem automaticamente quando:

┌──────────────────────────┬──────────────────────────────────────────────────────┐
│ QUANDO                    │ O QUE ACONTECE                                      │
├──────────────────────────┼──────────────────────────────────────────────────────┤
│ Você cria uma            │ O sistema cria um cartão no Pipeline com status     │
│ Proposta Técnica         │ "Aguardando Início". O tipo aparece como "PTC".     │
│                          │                                                       │
│ Você cria um Orçamento   │ O sistema cria um cartão no Pipeline. A origem      │
│                          │ aparece como "Orçamento".                            │
│                          │                                                       │
│ Você salva a             │ Se a Proposta Técnica já existia, o cartão é        │
│ Proposta Comercial       │ atualizado com o valor — mas só quando o valor     │
│                          │ está vazio ou zerado — e o tipo muda para "PTC".   │
│                          │                                                       │
│ Você cria PTC separada   │ São criados DOIS cartões: um para PT e um para PC. │
│ (PT + PC em 2 arquivos) │                                                       │
└──────────────────────────┴──────────────────────────────────────────────────────┘

💡 Resumo: Não precisa sair cadastrando cliente no Pipeline. Basta criar a
   Proposta Técnica ou o Orçamento que o cartão aparece sozinho.

A BOLINHA COLORIDA no canto direito indica o tempo sem contato com o cliente:

┌──────────────────────┬──────────────────────────────────────────────────────────┐
│ BOLINHA              │ SIGNIFICADO                                              │
├──────────────────────┼──────────────────────────────────────────────────────────┤
│ 🟢 Verde             │ Contato recente (até 3 dias)                             │
│ 🟡 Amarela           │ De 4 a 7 dias sem contato                               │
│ 🔴 Vermelha          │ Mais de 7 dias sem contato — precisa ligar!              │
│ ⚫ Cinza              │ Nenhum contato registrado ainda                          │
└──────────────────────┴──────────────────────────────────────────────────────────┘

📌 A bolinha é um ALERTA VISUAL. Se ela está vermelha, significa que o cliente
   pode estar esfriando. Hora de registrar uma interação!

📌 Sem nenhuma interação registrada, a bolinha conta os dias desde a CRIAÇÃO
   do cartão — por isso ela pode ficar amarela ou vermelha sozinha com o tempo.

┌─────────────────────────────────────────────────────────────────────────────────┐
│                                                                                 │
│  6. INTERAÇÕES (HISTÓRICO DE CONTATO)                                          │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘

Quando você clica em um cartão, abre um modal com DETALHES. Uma das seções
mais importantes é "Registrar Interação".

As interações são o HISTÓRICO de tudo que você fez com aquele cliente:

  • 📞 Ligação — Você ligou para o cliente
  • ✉️  E-mail — Você enviou um e-mail
  • 🤝 Reunião — Você se encontrou presencialmente ou por videoconferência
  • 💬 WhatsApp — Você conversou pelo WhatsApp
  • 📝 Outro — Qualquer outro tipo de contato

PARA CADA INTERAÇÃO, você registra:

  1. O TIPO (ligação, e-mail, reunião, WhatsApp, outro)
  2. A DATA (quando aconteceu)
  3. A DESCRIÇÃO (do que falaram, o que ficou combinado)
  4. O PRÓXIMO FOLLOW-UP (quando você vai entrar em contato de novo — o
     registro aceita também a HORA, e o alerta "Vencido" respeita essa hora)

✅ A bolinha colorida do cartão é atualizada automaticamente com base na data
   da última interação.

✅ Se você marcar um follow-up, o cartão mostra a data agendada.

✅ O histórico completo fica salvo e pode ser visto a qualquer momento.


┌─────────────────────────────────────────────────────────────────────────────────┐
│                                                                                 │
│  7. COMO MOVER CARTÕES ENTRE COLUNAS                                           │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘

Existem duas formas de mover um cartão:

─── FORMA 1: ARRASTAR (DRAG & DROP) ─────────────────────────────────────────────

  • Clique e segure o cartão com o mouse.
  • Arraste para a coluna desejada.
  • Solte.

  🔒 Só funciona para usuários com permissão (não funciona para vendedores).
  🔒 Só pode AVANÇAR o cartão (nunca voltar para uma coluna anterior).

─── FORMA 2: SUBIR REVISÃO (ação mais complexa) ─────────────────────────────────

  Explicado na seção 9.

🔒 REGRA IMPORTANTE DE AVANÇO:

  Se um cartão estiver "Fechado" ou "Perdido", ele NÃO pode voltar para
  outra coluna — o arrasto é recusado com aviso ("Proposta Fechada").
  Os botões Editar e Excluir continuam disponíveis para quem tem permissão.
  Se precisar de uma proposta limpa, use "Salvar como Novo(a)" na Proposta
  Técnica para criar uma CÓPIA.

Ao abrir um cartão, você pode clicar em "Editar" para alterar:

  ├────────────────────┼──────────────────────────────────────────────────────────┤

┌─────────────────────────────────────────────────────────────────────────────────┐
│                                                                                 │
│  9. SUBIR REVISÃO                                                              │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘

"Subir Revisão" é uma ação que você faz quando a proposta passou por uma etapa
e precisa ser atualizada para uma nova versão. É como dizer: "essa versão está
pronta, vamos para a próxima fase."

O QUE ACONTECE QUANDO VOCÊ SOBE UMA REVISÃO:

  1. O número da revisão aumenta (Rev00 → Rev01 → Rev02...)
  2. O cartão VOLTA para "Aguardando Início" — porque a nova revisão
     precisa ser trabalhada novamente (um cartão em "Negociação" também
     volta para o início; só uma revisão marcada como "Consolidada" em
     outra coluna vai direto para "Negociação")
  3. O engenheiro responsável é LIMPO — você precisa atribuir um novo
     engenheiro (ou o mesmo) para a nova revisão
  4. Opcional: você pode marcar como "Consolidada"

  No diálogo você também DESCREVE a revisão (campo "Descrição da Revisão")
  e pode ajustar a Data de Entrega. O botão "Subir Revisão" só aparece em
  cartões que não estão em Em Elaboração, Fechado ou Perdido — e não
  aparece para vendedores.

─── O QUE É "CONSOLIDADA"? ─────────────────────────────────────────────────────

  Uma proposta "Consolidada" significa que a parte técnica já foi aprovada pelo
  cliente e agora a negociação é só comercial (preço, condições).

  Se você marca "Consolidada" ao subir revisão:
    • O cartão vai para "Negociação" em vez de "Aguardando Início"
      (a menos que ele já estivesse em "Negociação" — nesse caso ele
      volta para o início, como qualquer revisão)
    • Aparece o badge "Consolidada" no cartão

─── QUANDO USAR? ────────────────────────────────────────────────────────────────

  • Cliente aprovou o escopo técnico → suba revisão marcando "Consolidada"
   • Cliente pediu alterações no escopo → suba revisão SEM marcar consolidada
   • Você precisa emitir uma nova versão da proposta → suba revisão

─── O QUE ACONTECE NO SERVIDOR? ───────────────────────────────────────────────

  Quando você clica em "Subir Revisão", o GeraPro no servidor:

  1. Cria uma nova pasta de revisão (Rev01, Rev02, Rev03...)
  2. Copia os arquivos da revisão anterior para a nova pasta
     (PropostaTecnica.json, PropostaComercial.json, Precificacao.json, etc.)
  3. Cria um arquivo de log da revisão em "Log das Revisões/R01_*.json"
  4. Atualiza o cartão no Pipeline com o novo número de revisão


┌─────────────────────────────────────────────────────────────────────────────────┐
│                                                                                 │
│  10. ENGENHEIRO RESPONSÁVEL                                                    │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘

Quando um cartão está em "Aguardando Início", você precisa ATRIBUIR um
engenheiro responsável para elaborar a proposta.

No canto do cartão aparece um botão:
  • 🔴 "Eng. Resp.??" (vermelho) — Nenhum engenheiro atribuído
  • 🟣 "Eng. Resp. OK" (roxo) — Já tem engenheiro

Ao clicar, uma lista de engenheiros cadastrados aparece. Escolha um.

💡 O engenheiro responsável é LIMPO quando você sobe uma revisão, porque a
   nova revisão pode ser feita por outro engenheiro.


┌─────────────────────────────────────────────────────────────────────────────────┐
│                                                                                 │
│  11. EXPORTAR E IMPRIMIR PIPELINE                                               │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘

A barra superior tem quatro botões: Limpar Antigos (só Admin/Gerente),
Sincronizar, Imprimir e Exportar — os três últimos aparecem para todos os
níveis. Dá para exportar em dois formatos e também imprimir:

─── CSV (📥) — Botão "Exportar" no topo da tela ─────────────────────────────

  • UM RESUMO no começo do arquivo, mostrando quantos itens e o valor total
    em cada coluna
  • A LISTA COMPLETA de todos os cartões com: Cliente, Projeto, Valor, Status,
    Origem, Datas, Observações

  Abre no Excel, Google Planilhas ou qualquer editor de texto.

─── IMPRIMIR (🖨️) — Botão "Imprimir" no topo da tela ─────────────────────────

  Abre uma janela com duas opções de impressão:

  1. Gestão de Propostas — os KPIs do topo e uma tabela por etapa com
     Cliente, Projeto, Código, Tipo, Vendedor, Eng. Resp., Data Abertura,
     Status, Prazo (No Prazo / Último dia / Atrasado, calculado da Data de
     Entrega) e Valor, com o total geral no rodapé.
  2. Log das Revisões — o histórico completo de TODAS as PTCs: PTC, Projeto,
     Rev, Ação, Data/Hora, Eng. Resp., Vendedor, Status e Prazo.

  A impressão abre em nova janela e dispara o diálogo de impressão do
  navegador — escolha "Salvar como PDF" se quiser guardar o arquivo.

─── VER LOG (📥/📊) — Botão "Ver Log" no cartão ───────────────────────────────

  Todo cartão de proposta com pasta no servidor traz o botão "Ver Log".
  Ele abre a tabela de histórico daquela proposta com as colunas PTC, Rev,
  Data/Hora, Ação, Eng. Resp., Status, Valor, Consolidada e Prazo — e os
  botões CSV e XLSX para exportar esse histórico.

  Disponível apenas para cartões que possuem PTC física no servidor.


┌─────────────────────────────────────────────────────────────────────────────────┐
│                                                                                 │
│  12. LIMPEZA EM MASSA                                                          │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘

Com o tempo, o Pipeline acumula cartões perdidos e antigos. O botão "Limpar
Antigos" (🗑️) ajuda a organizar. Você escolhe os critérios:

  ┌──────────────────────────────────────────────────────────────────────────────┐
  │                                                                              │
  │  ☑ Status "Perdido" — Remove todos os cartões que estão como Perdido.       │
  │                                                                              │
  │  ☑ Sem contato há mais de [90] dias — Remove cartões abandonados.          │
  │                                                                              │
  │  ☑ Criado há mais de [180] dias — Remove cartões muito antigos.            │
  │                                                                              │
  └──────────────────────────────────────────────────────────────────────────────┘

💡 Use a Limpeza em Massa periodicamente (ex: uma vez por mês) para manter
   o Pipeline organizado.

⚠️ Cartões vindos de ORÇAMENTOS não são removidos pela Limpeza em Massa,
   apenas cartões de PTC.


┌─────────────────────────────────────────────────────────────────────────────────┐
│                                                                                 │
│  13. SINCRONIZAR                                                               │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘

O botão "Sincronizar" (🔄) — presente para todos os níveis, inclusive
vendedores — verifica se as pastas das PTCs ainda existem no servidor.
Se uma pasta foi deletada manualmente, o cartão correspondente é removido
do Pipeline.

💡 Use quando você excluiu PTCs diretamente pelo disco e quer limpar os
   cartões órfãos.

┌─────────────────────────────────────────────────────────────────────────────────┐
│                                                                                 │
│  16. PROBLEMAS COMUNS E SOLUÇÕES                                                │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────────┐
│  PROBLEMA: "O Pipeline está vazio e eu já criei PTCs"                         │
│  SOLUÇÃO:  Verifique o nível do seu usuário. Se for "vendedor", você só vê    │
│            os cartões onde você é o vendedor. Peça ao admin para verificar     │
│            se o vendedor está correto na PTC.                                  │
│                                                                                 │
│  PROBLEMA: "Não consigo arrastar o cartão para outra coluna"                  │
│  SOLUÇÃO:  (a) Se você é vendedor, não pode arrastar — é proposital.          │
│            (b) Só pode AVANÇAR o cartão, nunca voltar.                        │
│            (c) Se o cartão está Fechado ou Perdido, está bloqueado.            │
│                                                                                 │
│  PROBLEMA: "O cartão sumiu depois que movi para Perdido"                      │
│  SOLUÇÃO:  Ele não sumiu — está na coluna "Perdido". Role a tela para a       │
│            direita ou use o recolhimento de colunas para ver todas.            │
│                                                                                 │
│  PROBLEMA: "Criei um Orçamento, mas não apareceu no Pipeline"                │
│  SOLUÇÃO:  Pode levar alguns segundos para sincronizar. Feche e abra o        │
│            Pipeline. Se ainda não aparecer, clique em "Sincronizar".           │
│                                                                                 │
│  PROBLEMA: "Quero editar um cartão mas o botão Editar não aparece"            │
│  SOLUÇÃO:  Se você é vendedor, não pode editar. Se o cartão veio de um        │
│            Orçamento, a edição não está disponível porque as informações      │
│            vêm do orçamento original.                                          │
│                                                                                 │
│  PROBLEMA: "O cartão está como Fechado mas preciso reabrir"                   │
│  SOLUÇÃO:  O arrasto de volta é bloqueado — Fechado e Perdido não voltam.     │
│            Para corrigir dados, use "Editar" no modal de detalhes: a edição   │
│            continua liberada para quem tem permissão. Se precisar começar     │
│            do zero, crie uma cópia com "Salvar como Novo(a)" na PTC.          │
│                                                                                 │
│  PROBLEMA: "Tem muitos cartões perdidos, quero limpar"                        │
│  SOLUÇÃO:  Use o botão "Limpar Antigos" no topo da tela. Selecione            │
│            "Status Perdido" e confirme.                                        │
│                                                                                 │
│  PROBLEMA: "As informações do cartão estão desatualizadas"                    │
│  SOLUÇÃO:  Edite o cartão manualmente (botão "Editar" no modal de detalhes).  │
│            Ou salve novamente a Proposta Comercial para atualizar o valor.     │
│                                                                                 │
│  PROBLEMA: "O valor do cartão está zerado"                                    │
│  SOLUÇÃO:  O valor vem da Precificação quando a Proposta Comercial é salva —  │
│            mas só preenche cartões vazios ou zerados; valores já digitados    │
│            são preservados. Se você só criou a Proposta Técnica, o valor      │
│            fica R$ 0,00 — é normal; a PT não tem valores financeiros.         │
│                                                                                 │
│  PROBLEMA: "A bolinha está vermelha mas eu liguei ontem"                      │
│  SOLUÇÃO:  A bolinha olha a data da ÚLTIMA INTERAÇÃO registrada — sem         │
│            interação, conta os dias desde a criação do cartão. Se você ligou  │
│            mas não registrou, o sistema não sabe. Registre a interação no     │
│            modal de detalhes para a bolinha ficar verde.                      │
│                                                                                 │
│  PROBLEMA: "Não consigo ver a coluna Perdido"                                 │
│  SOLUÇÃO:  As colunas têm rolagem horizontal. Role para a direita usando a    │
│            barra de rolagem na parte inferior do quadro Kanban.               │
└─────────────────────────────────────────────────────────────────────────────────┘


┌─────────────────────────────────────────────────────────────────────────────────┐
│                                                                                 │
│  17. LOGS DAS AÇÕES (HISTÓRICO COMPLETO)                                      │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘

Toda ação importante em um cartão do Pipeline é registrada em um arquivo de log
no servidor, dentro da pasta "Log das Revisões" da PTC. Isso cria um histórico
completo e auditável de tudo que aconteceu com aquele negócio.

─── QUAIS AÇÕES SÃO REGISTRADAS? ───────────────────────────────────────────────

  • 🆕 Criação       — "Nova PT Criada" / "Nova PC Criada"
  • ✏️ Edição         — "Campos editados: cliente, valor, observações"
  • 🔀 Movimentação  — "Proposta movida de Em Elaboração para Proposta Enviada"
  • 🗑️ Exclusão      — "Cartão 'Usina São Francisco' excluído"
  • 👤 Atribuição    — "Engenheiro responsável: Carlos Silva"
  • 💬 Interação     — "Interação (ligação): Cliente pediu desconto"

─── ONDE FICAM OS ARQUIVOS? ────────────────────────────────────────────────────

  PTCs físicas:    /data/PTCs/26061101-PT/Log das Revisões/ACT_*.json
  PTCs separadas:  /data/PTCs/26061101-PT_REV01/Log das Revisões/ACT_*.json

─── EXPORTAR O LOG (CSV OU XLSX) ───────────────────────────────────────────────

  No botão "Ver Log" do cartão, os botões 📥 CSV e 📊 XLSX geram o histórico
  de ações e revisões daquela PTC — a mesma tabela que o modal exibe na tela.

─── PARA QUE SERVEM? ────────────────────────────────────────────────────────────

  • Auditoria: saber exatamente quem fez o quê e quando
  • Histórico: recuperar versões anteriores de decisões
  • Rastreabilidade: entender por que um cartão mudou de status


┌─────────────────────────────────────────────────────────────────────────────────┐
│                                                                                 │
│  18. NOTIFICAÇÕES NO TELEGRAM                                                  │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘

O GeraPro pode enviar mensagens no Telegram sempre que algo acontece no Pipeline
Comercial, para que você fique sabendo em tempo real mesmo fora do sistema.

─── EVENTOS QUE DISPARAM NOTIFICAÇÃO ───────────────────────────────────────────

  • 🆕 Criação       — Um novo cartão aparece no Pipeline
  • ✏️ Edição         — Campos de um cartão são alterados
  • 🔀 Movimentação  — O cartão é movido de uma coluna para outra
  • 🗑️ Exclusão      — Um cartão é removido do Pipeline

─── QUEM RECEBE AS NOTIFICAÇÕES? ───────────────────────────────────────────────

  Apenas usuários com perfil Admin ou Engenheiro que tenham configurado o
  Chat ID do Telegram. Vendedores não recebem notificações.

─── COMO CONFIGURAR? ───────────────────────────────────────────────────────────

  1. Vá em Configurações → seção "Telegram"
  2. Informe o Token do Bot (criado pelo @BotFather no Telegram)
  3. Para cada usuário Admin/Engenheiro, preencha o Chat ID
  4. Clique em "Salvar Configurações do Telegram"
  5. Use o botão "Testar" para verificar se está funcionando

─── EXEMPLO DE MENSAGEM ────────────────────────────────────────────────────────

  🆕 *GeraPro — Pipeline*
  *PTC:* 26061101-PT
  *Cliente:* Usina São Francisco
  *Projeto:* CCM-BT e QGF
  *Ação:* Nova PT Criada
  *Responsável:* João
  *Vendedor:* Maria

💡 O Telegram é um canal EXTRA de notificação. O sistema continua funcionando
   normalmente dentro do GeraPro — as mensagens são apenas um aviso adicional.
   As notificações são enviadas apenas para os perfis Admin e Engenheiro.
