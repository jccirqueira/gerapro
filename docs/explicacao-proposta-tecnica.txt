┌─────────────────────────────────────────────────────────────────────────────────┐
│                                                                                 │
│  1. O QUE É A PROPOSTA TÉCNICA?                                                │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘

Imagine que você vai contratar uma construtora para fazer uma casa. Antes de
discutir preço, você precisa de uma PLANTA — um documento que mostra:

  • Quantos cômodos a casa vai ter
  • O tamanho de cada cômodo
  • Que materiais vão ser usados (tijolo, concreto, telha)
  • Onde ficam as instalações elétricas e hidráulicas

A Proposta Técnica no GeraPro é exatamente isso: a "planta" do fornecimento
elétrico. Ela descreve:

  • Quais painéis elétricos estão sendo fornecidos (CCM, QGBT, Cubículos MT...)
  • As especificações técnicas de cada um (tensão, corrente, dimensões)
  • Os motores e cargas que cada painel vai alimentar
  • A lista completa de materiais (disjuntores, cabos, contatores)
  • O escopo do fornecimento (o que está incluso e o que não está)
  • Os fabricantes preferenciais de cada componente
  • As revisões e versões do documento

╔══════════════════════════════════════════════════════════════════════════════════╗
║                                                                                  ║
║   ✅  Proposta Técnica = Documento técnico (o "o quê" vai ser fornecido).       ║
║   ✅  Proposta Comercial = Preços e condições (o "quanto" vai custar).         ║
║                                                                                  ║
╚══════════════════════════════════════════════════════════════════════════════════╝


┌─────────────────────────────────────────────────────────────────────────────────┐
│                                                                                 │
│  Onde a Proposta Técnica se encaixa no fluxo de trabalho?                     │
│                                                                                 │
│  1. Você cria uma PTC (Proposta Técnico-Comercial) — é a pasta do projeto     │
│  2. ❗ Você ABRE a Proposta Técnica — descreve os equipamentos                │
│  3. Cria os equipamentos (painéis) e suas cargas (motores)                     │
│  4. Associa Típicos de Partida a cada carga                                   │
│  5. O sistema monta a Lista de Materiais automaticamente                      │
│  6. Configura escopo, exclusões, lista de fornecedores                        │
│  7. ❗ Depois vai para a Precificação (definir preços)                        │
│  8. Depois para a Proposta Comercial (condições de pagamento)                 │
│  9. Exporta o documento em Word para entregar ao cliente                      │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘

│  2. TIPOS DE EQUIPAMENTOS QUE VOCÊ PODE CADASTRAR                             │
│                                                                                 │

Na Proposta Técnica, cada equipamento é um tipo específico de painel ou sistema.
Os tipos disponíveis são:

┌────────────────────────┬──────────────────────────────────────────────────────┐
│ TIPO                   │ O QUE É                                               │
├────────────────────────┼──────────────────────────────────────────────────────┤
│ CCM-BT                 │ Centro de Controle de Motores — Baixa Tensão.        │
│                        │ O mais comum: distribui energia para vários motores. │
│                        │                                                       │
│ QGBT                   │ Quadro Geral de Baixa Tensão — a "entrada" do        │
│                        │ sistema elétrico. Distribui para os demais quadros.  │
│                        │                                                       │
│ CUB-MT                 │ Cubículo de Média Tensão (13,8KV, 34,5KV...).       │
│                        │ Para indústrias que recebem energia em MT.           │
│                        │ Tem sua própria tabela de "Cubículos" no lugar       │
│                        │ de cargas comuns. Tipos disponíveis: CE (Entrada),  │
│                        │ CS (Seccionamento), CM (Medição), CP (Proteção),    │
│                        │ CT (Transformação), CPS (Proteção Contra Surtos),   │
│                        │ CAN (Aterramento de Neutro).                         │
│                        │ Normas padrão: NBR IEC 62271, NR-10, NR-12.         │
│                        │ Tensão padrão: 13,8kV / Isolamento: 15kV /          │
│                        │ ICC: 16kA/1s / IP: IP-4X.                           │
│                        │                                                       │
│ QTA                    │ Quadro de Transferência Automática — chaveia entre   │
│                        │ rede normal e gerador.                                │
│                        │                                                       │
│ QDL                    │ Quadro de Distribuição de Iluminação.                │
│                        │                                                       │
│ QDF                    │ Quadro de Distribuição de Força.                     │
│                        │                                                       │
│ PNC                    │ Painel de Controle — para comando e supervisão.      │
│                        │                                                       │
│ BC                     │ Banco de Capacitores — correção de fator de potência.│
│                        │                                                       │
│ PLC                    │ Painel de Automação (CLP) — o "cérebro" da fábrica.  │
│                        │ Tem lista de I/O (entradas e saídas).                │
│                        │                                                       │
│ REM                    │ Remota de Automação — expande as I/O do PLC.         │
│                        │                                                       │
│ TR-MT                  │ Transformador de Média Tensão.                       │
│                        │                                                       │
│ SEU                    │ Subestação Elétrica Unitária — agrupa transformador  │
│                        │ + painéis em uma única subestação.                   │
│                        │                                                       │
│ ELETROCENTRO           │ Sala Elétrica Modular — uma "salinha" pré-fabricada │
│                        │ que abriga os painéis.                               │

📌 Cada tipo de equipamento tem campos e sub-abas diferentes. Por exemplo:
   PLC tem aba "Lista de I/O", CCM-BT tem aba "Cargas" e "Barramentos",
   SEU não tem cargas próprias (agrupa outros equipamentos).

─── SIDEBAR ───────────────────────────────────────────────────────────────────────

  • Lista todos os equipamentos da proposta em ordem.
  • Você pode ARRASTAR para reordenar.
  • SEUs aparecem como pastas expansíveis com seus componentes dentro.
  • Clique em um equipamento para selecionar e ver suas sub-abas.
  • Botões: "Novo Equipamento", "Estimar Mão de Obra", "Adicionar SEU".

──AS SUB-ABAS (variam conforme o tipo de equipamento) ──────────────────────────

  Para a maioria dos tipos (CCM-BT, QGBT, QTA, BC, PNC, QDL, QDF):

    • FICHA TÉCNICA — Tensão, ICC, IP, dimensões, pintura, normas de ensaio, etc.
    • NORMAS — Normas técnicas aplicáveis (NBR IEC 61439, NR-10, etc.)
    • CARGAS — Motores, alimentadores e cubículos ligados ao painel
    • INVÓLUCROS — Tipo de gabinete, material, cor, acesso, quantidade de armários
    • BARRAMENTOS — Barramento principal, derivação e terra (material, corrente)
    • DESVIOS TÉCNICOS — Itens que fogem ao padrão com justificativa
    • MÃO DE OBRA — Estimativa de horas de montagem
    • DESPESAS — Custos adicionais por equipamento
    • CÁLCULOS ELÉTRICOS — Potência total, corrente nominal, disjuntor sugerido
    • CÁLCULOS MECÂNICOS — Dimensões totais, peso do barramento de cobre
    • LAYOUT SUGERIDO — Arranjo físico dos cubículos com canvas visual

  Para PLC / REM:

    • FICHA TÉCNICA — Especificações do painel de automação
    • NORMAS — Normas aplicáveis
    • LISTA DE I/O — Racks, slots e canais de entrada/saída
    • BOM (Lista de Materiais) — Materiais do painel de automação
    • DESVIOS TÉCNICOS — Itens fora do padrão com justificativa
    • MÃO DE OBRA
    • DESPESAS

  Para TR-MT (Transformador):

    • FICHA TÉCNICA — Potência, tensões primária/secundária, etc.
    • MATERIAIS — Materiais específicos do transformador
    • NORMAS
    • DESVIOS
    • DESPESAS

  Para SEU (Subestação):

    • FICHA TÉCNICA — Tensão primária
    • DESVIOS
    • DESPESAS

  Para ELETROCENTRO:

    • FICHA TÉCNICA — Dimensões da sala, módulos, peso, capacidade
    • ELETROCENTRO — Escopo específico da sala elétrica (matriz de responsabilidades)
    • MATERIAIS
    • NORMAS
    • DESVIOS
    • MÃO DE OBRA
    • DESPESAS
    • CÁLCULOS MECÂNICOS


┌─────────────────────────────────────────────────────────────────────────────────┐
│                                                                                 │
│  7. SUB-ABA: CARGAS (LOADS) E TÍPICOS                                          │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘

As CARGAS representam os motores ou alimentadores que o painel vai atender.

Exemplo: Um CCM-BT pode ter estas cargas:
  • M-01: Bomba de Água 50CV (com Inversor)
  • M-02: Exaustor 30CV (com Soft-Starter)
  • M-03: Correia Transportadora 10CV (Partida Direta)
  • C-01: Alimentador 100A (sem motor)

─── CAMPOS DE CADA CARGA ─────────────────────────────────────────────────────────

┌───────────────────────┬─────────────────────────────────────────────────────────┐
│ CAMPO                 │ O QUE É                                                 │
├───────────────────────┼─────────────────────────────────────────────────────────┤
│ TAG                   │ Identificação da carga (ex: M-01, C-01).               │
│ Descrição             │ O que é (ex: "Bomba de Água 01").                      │
│ Potência (CV)         │ Potência do motor em Cavalos-Vapor.                    │
│ Tensão (V)            │ Tensão de alimentação do motor.                        │
│ Corrente (A)          | ⛔ Auto — calculada pela fórmula (potência × FP, etc.) │
│ Regime                │ S1 (contínuo), S2 (curta duração) ou S3 (intermitente).│
│ Tipo                  │ Tipo de partida: IF (Inversor), SS (Soft-Starter),      │
│                       │ PD (Partida Direta), ET (Estrela-Triângulo),            │
│                       │ AL (Alimentador)...                                     │
│ Típico                │ 🎯 **Campo mais importante**: seleciona o Típico       │
│                       │ de Partida que contém a lista de materiais.            │
└───────────────────────┴─────────────────────────────────────────────────────────┘

──COMO FUNCIONA O TÍPICO ──────────────────────────────────────────────────────

  Ao selecionar um Típico:
  1. O sistema FILTRA os típicos compatíveis (mesma potência, tensão e tipo)
  2. Ao escolher, os parâmetros elétricos são preenchidos automaticamente
  3. A Lista de Materiais da carga é carregada a partir do típico
  4. O custo da carga é calculado (soma dos materiais)

─── AÇÕES DISPONÍVEIS ────────────────────────────────────────────────────────────

  • ➕ Adicionar carga
  • 📋 Duplicar carga
  • 📄 Importar cargas do Excel
  • 💾 Salvar lista como modelo
  • 📂 Carregar lista de um modelo salvo
  • 🗑️ Limpar todas as cargas

─── PARA CUB-MT ──────────────────────────────────────────────────────────────────

  Em vez de Típicos de Partida, os Cubículos MT usam "cubiculos" — que são
  os modelos de cubículo de média tensão (entrada, saída, medição, etc.).

A Ficha Técnica é a primeira sub-aba de cada equipamento. Ela reúne as
especificações técnicas do painel. Os campos variam conforme o tipo.

─── CAMPOS ESPECÍFICOS POR TIPO ─────────────────────────────────────────────

  • CUB-MT: tensão nominal (13,8kV), isolamento (15kV), ICC (16kA/1s),
    IAC (AFLR), perda de arco (LSC-2B), IP (IP-4X)
  • TR-MT: potência (kVA), tensão primária (ex: 13,8kV), tensão secundária
    (ex: 380V), grupo de ligação, impedância (%), nível de isolamento
  • SEU: tensão primária, tipo de subestação
  • ELETROCENTRO: dimensões da sala (L×C×A), número de módulos, pé direito,
    peso por metro quadrado, capacidade de ventilação
  • PLC/REM: processador, memória, protocolo de comunicação, fonte,
    interface de rede

│  23. SEU (SUBESTAÇÃO ELÉTRICA UNITÁRIA)                                       │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘

A SEU é um recurso especial que permite AGRUPAR equipamentos em uma subestação.

─── POR QUE USAR? ────────────────────────────────────────────────────────────────

  Quando você fornece uma subestação completa (transformador + painéis), o
  conjunto é classificado como "Subestação Unitária" e tem benefício fiscal:
  o IPI dos componentes é ISENTO.

─── COMO FUNCIONA ────────────────────────────────────────────────────────────────

  1. Você cria os equipamentos normalmente (TR-MT, CCM-BT, etc.)
  2. Clique no botão "Adicionar SEU"
  3. Dê um nome para a SEU (ex: "SEU-01")
  4. Selecione quais equipamentos fazem parte dela
  5. ✅ Pronto! Os equipamentos selecionados viram "componentes" da SEU

─── O QUE MUDA ───────────────────────────────────────────────────────────────────

  • Na SIDEBAR, a SEU aparece como pasta expansível com os componentes dentro
  • No ESCOPO, aparecem itens específicos "Subestação SEU-01 — N equipamento(s)"
  • Na PRECIFICAÇÃO, os componentes da SEU têm IPI = 0 (isento)
  • É possível DESFAZER a SEU (botão "Desfazer SEU") — os componentes voltam
    a ter IPI normal

⚠️ Cuidado: desfazer uma SEU afeta a Precificação (o IPI volta a ser calculado).


┌─────────────────────────────────────────────────────────────────────────────────┐
│                                                                                 │
│  24. MÃO DE OBRA (ESTIMATIVA AUTOMÁTICA)                                      │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘

Na sub-aba "Mão de Obra" de cada equipamento, o sistema pode CALCULAR
automaticamente quantas horas de trabalho são necessárias para montar o painel.

─── COMO FUNCIONA ────────────────────────────────────────────────────────────────

  1. O sistema olha os Típicos de Partida associados às cargas
  2. Aplica "Regras de Derivação" — regras que definem quantas horas cada
     tipo de componente leva para montar
  3. Combina com as "Composições de Mão de Obra" — perfis de trabalhador
     (eletricista, técnico, ajudante) com seus custos horários
  4. Gera uma estimativa detalhada: "Horas de Eletricista: 40h", "Horas de
     Técnico: 20h", etc.

─── COMO USAR ────────────────────────────────────────────────────────────────────

  • Clique no botão "🔧 Estimar Mão de Obra" na sidebar
  • O sistema calcula para TODOS os equipamentos de uma vez
  • Você pode ver o detalhamento por equipamento na sub-aba "Mão de Obra"
  • Os valores de horas vão para a Precificação como custo de mão de obra

💡 Se preferir, você pode digitar as horas manualmente em vez de usar o
   cálculo automático.


┌─────────────────────────────────────────────────────────────────────────────────┐
│                                                                                 │
│  25. EXPORTAR PARA WORD                                                        │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘

O botão "📄 Exportar Word" gera um documento .docx profissional usando:

  • **Docxtemplater** — Motor que preenche um modelo do Word com os dados
  • **PizZip** — Biblioteca para manipular arquivos .docx
  • **ImageModule** — Para incluir logos e imagens no documento

──O QUE VAI NO DOCUMENTO ──────────────────────────────────────────────────────

  O template `TEMPLATE_TEC.docx` é preenchido com:

  • Dados do cliente (razão social, CNPJ, endereço, contato)
  • Dados da proposta (projeto, referência, código, data)
  • Engenheiro responsável, vendedor
  • Revisão atual
  • **Lista de equipamentos** — Cada equipamento vira uma seção no documento
    com suas especificações técnicas completas (tensão, ICC, IP, dimensões,
    cargas, barramentos, etc.)
  • **Escopo** — Tabela com responsabilidades
  • **Vendor List** — Tabela de fabricantes
  • **Exclusões**
  • **Assinaturas**

📌 O arquivo gerado é salvo como `Proposta_Tecnica_{projeto}.docx`.

📌 Você pode personalizar o modelo `TEMPLATE_TEC.docx` (ele fica na pasta
   raiz do sistema) para incluir o logotipo da sua empresa, cores, etc.

⚠️ A exportação é BLOQUEADA se a proposta estiver em modo somente leitura
   (Fechada/Perdida no Pipeline).

│                                                                                 │
│  26. SALVAR COMO NOVO                                                          │

O botão "📋 Salvar como Novo" permite criar uma CÓPIA da proposta para

─── OPÇÕES DISPONÍVEIS ───────────────────────────────────────────────────────────

  │  │                                                                        │ │
  │  │ ● Criar nova PTC (arquivo único)                                      │ │

┌─────────────────────────────────────────────────────────────────────────────────┐
│                                                                                 │
│  27. MODO SOMENTE LEITURA                                                     │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘

Quando um cartão no Pipeline Comercial está como "Fechado" ou "Perdido", a
Proposta Técnica associada entra em MODO SOMENTE LEITURA.

─── O QUE ACONTECE ───────────────────────────────────────────────────────────────

  • Aparece um AVISO VERMELHO no topo da tela:
    "SOMENTE LEITURA — Esta proposta está Fechada/Perdida no Pipeline."
  • TODOS os campos ficam desabilitados — não é possível editar nada
  • O botão "Exportar Word" fica bloqueado
  • O botão "Salvar" não funciona
  • O único botão que funciona é "Salvar como Novo" (para criar uma cópia)

─── POR QUE ISSO EXISTE? ─────────────────────────────────────────────────────────

  Para garantir a INTEGRIDADE das propostas já decididas. Se o cliente já
  aprovou ou recusou, não faz sentido alterar o documento depois.

  Se precisar fazer alterações, crie uma cópia com "Salvar como Novo".


┌─────────────────────────────────────────────────────────────────────────────────┐
│                                                                                 │
│  28. DICAS IMPORTANTES                                                          │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘

✅  **Sempre salve antes de trocar de aba.** O sistema captura os dados da aba
    atual quando você muda para outra. Se não salvar, pode perder alterações.

✅  **Mantenha os Típicos atualizados.** A qualidade da Lista de Materiais
    depende diretamente dos Típicos de Partida. Se eles estiverem desatualizados,
    a LM vai ficar incorreta.

✅  **Use a SEU quando aplicável.** Se você está fornecendo uma subestação
    completa, agrupar em SEU pode reduzir IPI e deixar o escopo mais claro.

✅  **Sincronize o Escopo** sempre que alterar os equipamentos. Os itens
    auto-gerados precisam ser atualizados.

✅  **Preencha a Especificação Técnica** de cada equipamento com cuidado.
    É isso que o cliente vai ler no documento Word.

✅  **Configure a Vendor List** corretamente. Ela evita dúvidas na hora da
    compra: "Qual disjuntor eu uso? — O que está na vendor list."

✅  **Para PLC/REM**, preencha a Lista de I/O (racks, slots, canais). O sistema
    gera automaticamente a BOM (lista de materiais de automação).

⚠️  **Não misture equipamentos de clientes diferentes na mesma PTC.** Cada
    PTC é um projeto. Crie uma nova PTC para cada cliente.

⚠️  **Propostas Fechadas/Perdidas são bloqueadas.** Se precisar alterar, use
    "Salvar como Novo" para criar uma cópia editável.

⚠️  **O custo dos materiais vem dos Típicos.** Se o preço no catálogo mudou,
    use "Recalcular Custos" nos Típicos e depois reabra a Proposta Técnica.

┌─────────────────────────────────────────────────────────────────────────────────┐
│                                                                                 │
│  30. PROBLEMAS COMUNS E SOLUÇÕES                                                │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────────┐
│  PROBLEMA: "Não consigo editar os campos — tudo está desabilitado"            │
│  SOLUÇÃO:  A proposta está em modo SOMENTE LEITURA. Verifique se o cartão    │
│            no Pipeline não está como "Fechado" ou "Perdido". Se estiver,      │
│            use "Salvar como Novo" para criar uma cópia editável.              │
│                                                                                 │
│  PROBLEMA: "A Lista de Materiais está vazia"                                 │
│  SOLUÇÃO:  Você precisa associar Típicos de Partida às cargas. Sem típico,   │
│            não há materiais. Vá na sub-aba "Cargas" e selecione um típico    │
│            para cada carga.                                                    │
│                                                                                 │
│  PROBLEMA: "Os valores na LM estão com preço antigo"                         │
│  SOLUÇÃO:  Os preços vêm dos Típicos. Vá no módulo de Típicos, abra o        │
│            típico e clique em "Recalcular Custos" para atualizar do           │
│            catálogo. Depois volte na Proposta Técnica e recarregue.          │
│                                                                                 │
│  PROBLEMA: "Não encontro o típico que preciso na carga"                      │
│  SOLUÇÃO:  O sistema FILTRA os típicos por potência, tensão e tipo. Se o     │
│            típico não aparece, verifique se os parâmetros da carga            │
│            correspondem aos do típico. Ex: carga 50CV não vai mostrar        │
│            típico de 75CV.                                                    │
│                                                                                 │
│  PROBLEMA: "O escopo não mostra todos os equipamentos"                       │
│  SOLUÇÃO:  Clique em "Sincronizar do Equipamento" para atualizar os itens    │
│            auto-gerados.                                                      │
│                                                                                 │
│  PROBLEMA: "O campo de corrente da carga está zerado"                        │
│  SOLUÇÃO:  Preencha a potência (CV), tensão, FP e rendimento. A corrente é  │
│            calculada automaticamente. Se ainda assim não aparecer, preencha  │
│            a "Corrente de Placa" manualmente.                                │
│                                                                                 │
│  PROBLEMA: "Exportei para Word mas faltam informações"                       │
│  SOLUÇÃO:  O template Word usa tags como {cliente}, {#lista_paineis}...      │
│            Se faltou informação, pode ser: (a) o campo não foi preenchido    │
│            na proposta; (b) o template não tem a tag correspondente.         │
│            Verifique o TEMPLATE_TEC.docx.                                     │
│                                                                                 │
│  PROBLEMA: "Quero adicionar um material extra na LM"                          │
│  SOLUÇÃO:  Use o botão "➕ Incluir Item" na visão LM. Isso adiciona o        │
│            material à carga sem alterar o típico original.                   │
│                                                                                 │
│  PROBLEMA: "Meu equipamento PLC não tem a aba de cargas"                     │
│  SOLUÇÃO:  É NORMAL. PLC e REM têm abas diferentes (Lista de I/O, BOM).     │
│            Cargas são para CCM-BT, QGBT e similares.                         │
│                                                                                 │
│  PROBLEMA: "Criei uma SEU mas o IPI continua sendo calculado"                │
│  SOLUÇÃO:  O IPI isento para componentes de SEU é aplicado na PRECIFICAÇÃO, │
│            não na Proposta Técnica. Abra a Precificação e veja se os         │
│            componentes aparecem com IPI = 0. Se não, desfaça a SEU e recrie. │
│                                                                                 │
│  PROBLEMA: "A aba Infraestrutura não aparece na minha proposta"               │
│  SOLUÇÃO:  A aba Infraestrutura fica entre Equipamentos e Escopo. Se você     │
│            não está vendo, pode ser que a tela esteja em resolução baixa —    │
│            use a rolagem horizontal das abas ou maximize o navegador.         │
│                                                                                 │
│  PROBLEMA: "Os valores da Infraestrutura não aparecem na Precificação"        │
│  SOLUÇÃO:  Os custos de Infraestrutura são transportados automaticamente       │
│            para a Precificação. Se não aparecerem, salve a Proposta Técnica   │
│            e recarregue a Precificação. Verifique também se os itens têm      │
│            custo unitário preenchido.                                          │
