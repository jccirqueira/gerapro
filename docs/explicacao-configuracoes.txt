┌─────────────────────────────────────────────────────────────────────────────────┐
│                                                                                 │
│  1. O QUE SÃO AS CONFIGURAÇÕES?                                                       │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘

Imagine que o GeraPro é um carro. As Configurações são o painel de instrumentos e os
comandos que você usa para configurar o carro antes de dirigir:

  • Quem é o dono do carro? (Dados da Empresa)
  • Quantas empresas usam o sistema? (Empresas — cada uma com seus próprios dados)
  • Qual o modelo do documento? (Modelos de Documentos — templates .docx)
  • Quem pode dirigir? (Usuários e seus níveis de acesso)
  • Quem são os vendedores? (cadastro de vendedores)
  • O carro tem piloto automático? (Inteligência Artificial)
  • Como receber notificações? (Telegram)
  • Como enviar e-mails? (E-mail — SMTP ou SendGrid)
  • Como personalizar o funil de vendas? (Funil CRM — estágios personalizáveis)
  • Qual a cor e o estilo do painel? (Personalização da tela de login)
  • Quanto custa a mão de obra do mecânico? (Custos de Mão de Obra)
  • Como fazer backup do carro? (Segurança e Backup)

Em resumo: as Configurações são a "central de controle" do sistema. Tudo que você
configurar aqui vale para o GeraPro inteiro.

│  4. EMPRESAS (TEMPLATES)                                                        │

O GeraPro permite cadastrar múltiplas empresas no sistema. Cada empresa tem
seus próprios templates de documentos (.docx), dados cadastrais e usuários

│ CAMPO / AÇÃO              │ O QUE É                                            │
├───────────────────────────┼─────────────────────────────────────────────────────┤
│ Nome da Empresa           │ Razão social ou nome fantasia.                      │
│                           │                                                     │
│ CNPJ                      │ CNPJ da empresa (com pontuação).                    │
│                           │                                                     │
│ Sigla                     │ Abreviação (ex: EMP1, WEG, ABC). Aparece no         │
│                           │ badge do cabeçalho do sistema.                      │
│                           │                                                     │
│ Plano                     │ Plano de assinatura ou classificação interna.       │
│                           │                                                     │
│ Ações (✏️)               │ Editar os dados da empresa.                         │
│                           │                                                     │
│ Ações (🗑️)              │ Excluir a empresa do sistema.                       │
└───────────────────────────┴─────────────────────────────────────────────────────┘

✅ Clique em "Adicionar" para incluir uma nova empresa.
✅ A tabela mostra todas as empresas cadastradas com Nome, CNPJ, Sigla e Plano.
✅ A empresa ativa aparece no cabeçalho com a sigla e uma cor configurável.
✅ Cada empresa pode ter templates, usuários e dados próprios e isolados.

📌 IMPORTANTE: Ao logar, cada usuário enxerga apenas os dados da empresa à
   qual ele está vinculado. Para trocar de empresa, é necessário logar com
   um usuário de outra empresa.

Aqui você define quais arquivos .docx o sistema vai usar como modelo (template)

┌───────────────────────────┬─────────────────────────────────────────────────────┐
│ CAMPO                     │ O QUE É                                            │
├───────────────────────────┼─────────────────────────────────────────────────────┤

   cada campo e depois em "Enviar".
✅ Se não houver template configurado, o sistema usa um template padrão
   (a última versão enviada para a empresa).
✅ Os templates ficam armazenados na pasta templates/{id_da_empresa}/ no
   servidor.

📌 Dica: Prepare os modelos .docx com marcadores como {{NOME_CLIENTE}},
   {{CIDADE}}, {{DATA}}, etc. O sistema substitui automaticamente pelos
   valores da proposta.

┌─────────────────────────────────────────────────────────────────────────────────┐

│  9. TELEGRAM (Notificações no Bot)                                             │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘

O GeraPro pode enviar mensagens no Telegram sempre que um cartão do Pipeline
Comercial é criado, editado, movido entre colunas ou excluído. Assim você fica
sabendo em tempo real, mesmo fora do sistema.

┌───────────────────────┬─────────────────────────────────────────────────────────┐
│ CAMPO                 │ O QUE É                                                │
├───────────────────────┼─────────────────────────────────────────────────────────┤
│ Token do Bot          │ Token do seu bot do Telegram, criado pelo @BotFather.   │
│                       │ É a "senha" que autoriza o GeraPro a enviar mensagens.  │
│                       │                                                         │
│ Chat ID               │ Identificador único de cada usuário no Telegram.        │
│                       │ Deve ser preenchido para cada Admin ou Engenheiro       │
│                       │ que quiser receber notificações.                        │
└───────────────────────┴─────────────────────────────────────────────────────────┘

✅ Clique em "Salvar Configurações do Telegram" para guardar o token e os Chat IDs.
✅ Use "Testar" para enviar uma mensagem de teste e confirmar que está funcionando.
✅ Quem recebe: apenas usuários com perfil Admin ou Engenheiro que tenham Chat ID
   preenchido. Vendedores e Visualizadores não recebem notificações.
✅ As notificações são enviadas para criação, edição, movimentação e exclusão de
   cartões no Pipeline Comercial.

│ 10. E-MAIL (Envio de E-mails)                                                  │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘

O GeraPro pode enviar e-mails diretamente pelo CRM usando dois provedores:
SMTP (servidor de e-mail tradicional) ou SendGrid (API na nuvem).

Escolha o provedor e preencha os campos correspondentes.

┌───────────────────────┬─────────────────────────────────────────────────────────┐
│ CAMPO                 │ O QUE É                                                │
├───────────────────────┼─────────────────────────────────────────────────────────┤
│ Provedor              │ SMTP (Servidor de E-mail) ou SendGrid (API)            │
│                       │                                                         │
│ Servidor SMTP         │ Endereço do servidor SMTP (ex: smtp.gmail.com).        │
│ (só SMTP)             │ Só aparece se o provedor for SMTP.                     │
│                       │                                                         │
│ Porta (só SMTP)       │ Porta do servidor (587 para TLS, 465 para SSL).       │
│                       │                                                         │
│ SSL/TLS (só SMTP)     │ Marque se usar porta 465.                              │
│                       │                                                         │
│ Usuário (só SMTP)     │ Seu e-mail ou usuário do servidor SMTP.                │
│                       │                                                         │
│ Senha (só SMTP)       │ Senha do e-mail. É criptografada ao salvar.            │
│                       │                                                         │
│ API Key (só SendGrid) │ Chave secreta da API do SendGrid.                      │
│                       │ É criptografada ao salvar no servidor.                  │
│                       │                                                         │
│ Nome do Remetente     │ Nome que aparece como remetente (ex: "GeraPro CRM").  │
│                       │                                                         │
│ E-mail do Remetente   │ E-mail que aparece como remetente. Obrigatório.        │
└───────────────────────┴─────────────────────────────────────────────────────────┘

✅ Botão "Salvar": guarda as configurações.
✅ Botão "Testar": envia um e-mail de teste para você mesmo confirmar que
   está funcionando.
✅ Os campos SMTP e SendGrid se alternam conforme o provedor selecionado
   (você só vê os campos do provedor escolhido).
✅ A senha SMTP e a API Key do SendGrid são criptografadas antes de salvar
   no banco de dados (ninguém consegue ler depois de salvas).

💡 Dica: Se você não tem um servidor SMTP próprio, pode usar o Gmail
   (smtp.gmail.com, porta 587) ou criar uma conta grátis no SendGrid.

⚠️ Importante: O e-mail do remetente precisa ser um e-mail real que aceite
   envio. Se usar SMTP do Gmail, você precisa ativar "Senha de App" ou
   "Acesso a apps menos seguros".

│ 11. FUNIL CRM (Estágios do Funil de Vendas)                                    │

O CRM do GeraPro permite que você personalize completamente os estágios do
funil de vendas. Você pode criar seus próprios estágios, renomear os existentes,
reordenar, mudar cores e definir regras de negócio.

┌───────────────────────────┬─────────────────────────────────────────────────────┐
│ CAMPO / AÇÃO              │ O QUE É                                            │
├───────────────────────────┼─────────────────────────────────────────────────────┤
│ Nome do Estágio           │ O nome que aparece no Kanban e na Lista.            │
│                           │                                                     │
│ ID do Estágio             │ Identificador interno (não precisa mudar).         │
│                           │                                                     │
│ Cor                       │ Cor do cartão no Kanban.                            │
│                           │                                                     │
│ Ícone                     │ Ícone que aparece no cartão (opcional).             │
│                           │                                                     │
│ Ordem                     │ Posição no funil (definida ao arrastar).            │
│                           │                                                     │
│ Padrão                    │ Se marcado, leads novos vão para este estágio.      │
│                           │ Apenas UM estágio pode ser padrão.                  │
│                           │                                                     │
│ Terminal                  │ Bloqueia arraste e interações. Usado para           │
│                           │ "Virou Proposta" e "Desqualificado".                │
│                           │                                                     │
│ Permite Proposta          │ Exibe o botão "Solicitar Proposta" neste estágio.   │
│                           │                                                     │
│ Registra Qualificação     │ Preenche automaticamente a data de qualificação.    │
│                           │                                                     │
│ Registra Conversão        │ Preenche automaticamente a data de conversão.       │
│                           │                                                     │
│ É Perda                   │ Marca como perda — abre modal de motivo ao entrar.  │
│                           │                                                     │
│ Motivos de Perda          │ Lista de motivos que aparece ao desqualificar.      │
│                           │ Ex: "sem orçamento", "concorrente", "outro".       │
└───────────────────────────┴─────────────────────────────────────────────────────┘

✅ Para adicionar um novo estágio, clique em "Adicionar Estágio".
✅ Para renomear ou configurar, clique no ícone de lápis ✏️.
✅ Para reordenar, arraste os estágios pela alça de arrasto (⠿).
✅ Para excluir, clique na lixeira 🗑️ (só permite se não houver leads no estágio).
✅ Clique em "Salvar Todas as Alterações" para persistir.
✅ Clique em "Restaurar Padrões" para voltar aos 8 estágios originais.

📌 Os 8 estágios padrão são: Novo, Tentando Contato, Contato Realizado,
   Qualificado, Agendado, Visita Realizada, Virou Proposta, Desqualificado.
   Você pode começar com eles e adaptar conforme sua necessidade.

📌 Se você excluir um estágio que tem leads, o sistema impede a exclusão.
   Primeiro mova os leads para outro estágio.

┌─────────────────────────────────────────────────────────────────────────────────┐
│                                                                                 │
│ 15. PROBLEMAS COMUNS E SOLUÇÕES                                                │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────────┐
│  PROBLEMA: "Mudei o Regime Tributário mas a Precificação não mudou"            │
│  SOLUÇÃO:  Feche a Precificação e abra novamente. O regime é lido apenas        │
│            quando o módulo é aberto.                                             │
│                                                                                 │
│  PROBLEMA: "A IA não está funcionando na importação"                           │
│  SOLUÇÃO:  Vá em Configurações > IA e clique em "Testar Conexão". Se falhar:          │
│            • Para Ollama: confirme que o programa Ollama está rodando no PC     │
│            • Para OpenAI: verifique se a chave da API está correta e com saldo  │
│                                                                                 │
│  PROBLEMA: "O custo de mão de obra está zerado na Proposta Técnica"            │
│  SOLUÇÃO:  Vá em Configurações > Tabela de Custos e preencha os valores das          │
│            funções que você usa. Ou use os valores padrão que já vêm no sistema.│
│                                                                                 │
│  PROBLEMA: "O nome da empresa aparece errado nos documentos"                   │
│  SOLUÇÃO:  Corrija em Configurações > Dados da Empresa e salve. Depois recarregue     │
│            a página para garantir que os documentos usem o novo nome.           │
│                                                                                 │
│  PROBLEMA: "Um funcionário saiu da empresa, como bloquear o acesso?"           │
│  SOLUÇÃO:  Vá em Configurações > Usuários, clique em "Gerenciar Usuários",            │
│            encontre o usuário e clique em 🗑️ (desativar). A pessoa para de     │
│            ter acesso imediatamente.                                             │
│                                                                                 │
│  PROBLEMA: "Perdi os dados do sistema!"                                        │
│  SOLUÇÃO:  Se você fez backup pelo botão "Baixar Backup JSON", vá em            │
│            Configurações > Segurança > "Restaurar Backup" e selecione o arquivo.      │
│            Se não fez backup, infelizmente não há como recuperar.               │
│                                                                                 │
│  PROBLEMA: "A tela de login não mudou depois de salvar"                        │
│  SOLUÇÃO:  Saia do sistema (clique no nome do usuário > Sair) e entre          │
│            novamente. A tela de login atualizada vai aparecer.                   │
│                                                                                 │
│  PROBLEMA: "Não consigo acessar as Configurações"                                    │
│  SOLUÇÃO:  Confirme que seu nível de acesso é "Admin". Apenas administradores  │
│            podem ver e editar configurações.                                     │
│                                                                                 │
│  PROBLEMA: "Cliquei em Testar no Telegram mas não recebi a mensagem"           │
│  SOLUÇÃO:  Verifique: (1) o Token do Bot está correto, (2) o Chat ID do        │
│            usuário foi preenchido, (3) o usuário já iniciou conversa com o     │
│            bot no Telegram (envie /start para o bot).                          │
│                                                                                 │
│  PROBLEMA: "O template .docx não aparece na lista de seleção"                  │
│  SOLUÇÃO:  Vá em Configurações > Modelos de Documentos e faça upload do arquivo      │
│            .docx. Certifique-se de estar logado na empresa correta, pois       │
│            cada empresa tem seus próprios templates.                           │
